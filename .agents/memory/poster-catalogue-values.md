---
name: Poster catalogue values
description: How to handle ambiguous financial fields when matching the supplied hotel-package poster.
---

Keep existing configured daily payouts when a reference poster leaves a daily figure blank. Do not infer that a blank means zero or change earning behavior during visual work.

**Why:** The supplied Grand Crown poster omits daily figures for several suites, while the live catalogue already contains configured daily rates. Replacing those rates with zero would stop earnings rather than simply match the artwork.

**How to apply:** Preserve live product IDs and payout settings when refreshing names and imagery. Ask for explicit financial instructions before changing ambiguous values or replacing records referenced by existing purchases.
